## Ваша первая SUP, доведённая до совершенства

Надувная SUP-доска SUP Explorer 11' — самая популярная универсальная модель в нашем каталоге: достаточно широкая для абсолютных начинающих, достаточно управляемая для гребцов среднего уровня и достаточно портативная для любого приключения. Исследуете ли вы спокойные озёра, медленно текущие реки или защищённые прибрежные воды, эта доска дарит уверенность и характеристики, которые вам нужны.

### Конструкция и долговечность

Сердцевина из ПВХ-ткани drop-stitch военного класса с рабочим давлением 15 PSI обеспечивает жёсткую платформу, не уступающую жёстким доскам. Широкая палуба 32 дюйма обеспечивает превосходную боковую устойчивость, что делает её одной из самых стабильных надувных SUP-доск в своём классе. Усиленные кромки защищают от ударов о пристани, камни и береговую линию.

### Полный комплект

Каждая SUP Explorer 11' поставляется как полный комплект для гребля:

- Надувная SUP-доска со съёмным центральным плавником
- Регулируемое алюминиевое весло из 3 частей
- Двухсторонний ручной насос со встроенным манометром
- Спиральный страховочный поводок с удобным креплением на щиколотке
- Премиальный дорожный рюкзак с мягкими лямками и карманом для плавника
- Ремонтный комплект с ПВХ-заплатками и инструментом для клапана

### Особенности продукта

- **Сердцевина из ПВХ-ткани drop-stitch**: Конструкция drop-stitch из тканого полиэстера военного класса с давлением 15 PSI для жёсткости, сопоставимой с жёсткой доской
- **Широкая палуба 32 дюйма**: Оптимальная ширина для превосходной боковой устойчивости, уверенности новичков и комфорта для йоги
- **Усиленные кромки**: Двухслойная защита боковины от истирания о пристани, ударов о береговые камни и повреждений
- **Конфигурация плавников 2+1**: Два литых боковых плавника для ровного хода плюс съёмный центральный плавник для маневренности
- **Шесть ПВХ-D-колец**: Крепление на носе (4 D-кольца) для сухих сумок и снаряжения плюс задние крепления для аксессуаров
- **Три эргономичные ручки**: Центральная ручка для переноски с неопреновой обмоткой плюс передняя и задняя транспортные ручки
- **Клапан Bravo**: Высокопроточный клапан для быстрой накачки и сдувания, совместимый со стандартными SUP-насосами
- **Полный комплект**: Включает надувную SUP-доску, регулируемое алюминиевое весло из 3 частей, двухсторонний насос с манометром, спиральный поводок, дорожный рюкзак и ремонтный комплект

### Условия применения

- **Озёра и водохранилища**: Зеркально спокойная вода, идеальная для фитнес-паблинга, йоги и семейных выходов
- **Медленные реки**: Спокойное течение с отзывчивым ходом
- **Защищённые прибрежные воды**: Закрытые бухты и заливы с умеренной волной
- **Путешествия и кемпинг**: Сдувается и упаковывается в компактный рюкзак для багажника автомобиля, автодома или ручной клади

### Для кого предназначена

- Начинающие гребцы и любители, которым нужна надёжная надувная SUP-доска
- Фитнес-любители, практикующие йогу и паблинг на спокойной воде
- Семьи, которым нужна общая доска, достаточно стабильная для гребцов любого уровня
- Путешественники, которым нужна портативная надувная SUP-доска для кемпинга и автопутешествий
